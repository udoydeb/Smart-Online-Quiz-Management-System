Smart Online Quiz Management System

A JavaFX + MySQL application to conduct and manage online quizzes. This page is a project landing page for the repository.

Repository: udoydeb/Smart-Online-Quiz-Management-System

View on GitHub CI / Actions

How to run

  • Clone the repo and open in your IDE (IntelliJ IDEA recommended).
  • Build with Maven: mvn clean package.
  • Configure MySQL and update the database connection settings in the project (see README).

Note: GitHub Pages hosts static sites only — the Java application runs locally or on a server.
